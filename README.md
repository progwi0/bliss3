Bliss 3 is a CSS stylesheet inspired by the sleek, modern look of Libadwaita from the GNOME desktop environment. It brings the clean, consistent, and elegant visual language of GNOME’s Adwaita design to the web — no JavaScript, just pure CSS.

    🎨 Minimalist light theme with Libadwaita vibes

    🌙 Optional dark mode support

    ⚡ Zero dependencies — just drop in the CSS

    🛠️ Great for dashboards, SPAs, personal sites, or anything you want to GNOME-ify

Simply link bliss3.css in your project and enjoy a beautiful, GNOME-style user interface on the web.
